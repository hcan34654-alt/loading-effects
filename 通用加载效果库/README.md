# 通用加载效果库

90 个不带行业元素的加载与等待效果，按颜色分 10 组，每个效果只用一个颜色加中性灰。

颜色和状态的对应：红色是出错、危险、录制、未读；橙色和黄色是进行中、等待、提醒；绿色是成功、通过；青、蓝、靛、紫、粉没有固定含义，黑灰用于骨架屏和中性提示。双击 `index.html` 浏览：按颜色筛选、搜索，悬停卡片可重播，点预览区看大图和 HTML / CSS / JS。

## 怎么用

`片段/` 里每个效果一个 html，双击可预览。文件分三段：颜色令牌、效果样式、预览舞台（复用时删掉）；HTML 在 `▼ ▲` 注释之间；带交互的在末尾有一段零依赖 `<script>`，里面的 `while(true)` 循环只为演示，接入时换成真实请求的回调。

换颜色：主色和它的深浅变化在顶部令牌 `--ld-main`、`--ld-main-d`、`--ld-accent`、`--ld-accent-l` 里。浅色底纹和阴影是写死的色值，换主色后需要一并替换。

所有效果都带 `prefers-reduced-motion` 降级。
